
# My Restaurant App (CN6035 Project)

# Περιγραφή Εφαρμογής
Η εφαρμογή "My Restaurant App" επιτρέπει στους χρήστες να πραγματοποιούν κρατήσεις σε εστιατόρια μέσω κινητής συσκευής (React Native). Το backend αναπτύχθηκε με Node.js και Express.js, ενώ η βάση δεδομένων χρησιμοποιεί MariaDB.

Η εφαρμογή παρέχει τις ακόλουθες δυνατότητες:
- Εγγραφή και σύνδεση χρηστών με χρήση JWT
- Αναζήτηση εστιατορίων ανά όνομα ή τοποθεσία
- Δημιουργία, επεξεργασία και διαγραφή κρατήσεων
- Προβολή ιστορικού κρατήσεων χρήστη

---

# Οδηγίες Εγκατάστασης

# Βάση Δεδομένων
Η βάση δεδομένων δημιουργείται εκτελώντας το αρχείο SQL που περιλαμβάνεται στο φάκελο `database/init.sql`.

# Backend
Ο server ξεκινά αφού γίνουν οι απαραίτητες ρυθμίσεις στα αρχεία `config/database.js` (στοιχεία σύνδεσης με τη βάση δεδομένων) και `config/secrets.js` (JWT secret).  

Οι απαραίτητες εξαρτήσεις εγκαθίστανται μέσω:
```bash
npm install
```
Η εκκίνηση γίνεται με:
```bash
node app.js
```

# Frontend
Η εφαρμογή React Native τρέχει αφού εγκατασταθούν οι εξαρτήσεις με:
```bash
npm install
```
και εκτελεστεί η εντολή:
```bash
npx react-native run-android
```
ή
```bash
npx react-native run-ios
```

# API Endpoints (ενδεικτικά)

| Endpoint                        | Περιγραφή                          |
|--------------------------------|------------------------------------|
| `POST /api/users/register`     | Εγγραφή νέου χρήστη                |
| `POST /api/users/login`        | Σύνδεση χρήστη                     |
| `GET /api/restaurants`         | Λίστα διαθέσιμων εστιατορίων       |
| `POST /api/bookings`           | Δημιουργία νέας κράτησης           |
| `PUT /api/bookings/:id`        | Ενημέρωση υπάρχουσας κράτησης      |
| `DELETE /api/bookings/:id`     | Διαγραφή κράτησης                  |
| `GET /api/users/reservations`  | Ιστορικό κρατήσεων χρήστη          |
